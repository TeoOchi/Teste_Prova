Sistema de Cadastro de Motores

Documentação Técnica do Protótipo em Python (CRUD em Memória)

Sobre o Projeto e Ambiente de Desenvolvimento

Este software foi desenvolvido como projeto prático no CentroWEG, a escola técnica do SENAI localizada dentro do parque fabril da WEG, em Jaraguá do Sul - SC.

O objetivo da aplicação é simular o gerenciamento de ativos industriais (motores elétricos) utilizando lógica de programação estruturada em Python, sem dependências de bancos de dados externos.

📍 Jaraguá do Sul, Santa Catarina 🏭 CentroWEG / SENAI 🐍 Python 3 (Monolítico)

Arquitetura e Funcionamento do Código

O script foi construído de forma monolítica em um único arquivo, dividindo responsabilidades em funções específicas e armazenando os dados temporariamente na memória RAM.

1. Estrutura de Dados (Array + Dict)

Utiliza uma lista global motores = [] (array dinâmico) onde cada elemento armazenado é um dicionário contendo as especificações técnicas: Número de Série, Fabricante, Modelo, Potência, Tensão e RPM.

2. Validação de Unicidade

Na função cadastrar_motor(), o sistema percorre o array antes de inserir um novo registro para garantir que não existam dois motores com o mesmo Número de Série.

3. Operações CRUD Completas

Implementa todo o ciclo de vida de dados: Create (Cadastrar), Read (Listar e Buscar), Update (Atualizar mantendo dados em branco) e Delete (Remover com confirmação).

4. Loop Principal (CLI)

A função main() mantém um laço while True que exibe o menu interativo no terminal e direciona o fluxo conforme a escolha do operador.

Mapeamento das Funções Python

Função Responsabilidade Estrutura Utilizada
exibir_menu() Imprime a interface textual de opções no console. Saída padrão (print)
cadastrar_motor() Coleta dados, valida o ID único e insere no array. Laço for + list.append()
listar_motores() Exibe todos os motores cadastrados de forma formatada. Função enumerate()
buscar_motor() Localiza e exibe a ficha completa via número de série. Busca linear no array
atualizar_motor() Altera atributos específicos preservando campos vazios. Mutação de dicionário
remover_motor() Exclui o registro após confirmação do usuário. list.pop(i)

Exemplo da Estrutura de Dados no Código

Trecho demonstrando como cada motor é estruturado dentro do array principal:

motores = []  # Array global em memória

novo_motor = {
    "numero_serie": "WEG-2026-001",
    "fabricante": "WEG",
    "modelo": "W22 IR3 Premium",
    "potencia": "10 CV",
    "tensao": "220V/380V",
    "rpm": "1750"
}

motores.append(novo_motor)
